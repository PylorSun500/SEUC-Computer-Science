# Windows 基础

## 鼠标和键盘的操作

1. Q: 一些常见的快捷键

| 功能              | 快捷键                                     |
| --------------- | --------------------------------------- |
| 显示 Windows 帮助   | <kbd>F1</kbd>                           |
| 复制整个屏幕的图像到剪贴板   | <kbd>PrintScreen</kbd>                  |
| 复制活动窗口的图像到剪贴板   | <kbd>Alt</kbd> + <kbd>PrintScreen</kbd> |
| 在安装的各个输入法之间进行切换 | <kbd>Ctrl</kbd> + <kbd>Shift</kbd>      |
| 在中、英文之间进行切换     | <kbd>Ctrl</kbd> + <kbd>Space</kbd>      |
| 在全、半角符号之间切换     | <kbd>Ctrl</kbd> + <kbd>.</kbd>          |

## 窗口及其基本操作

2. Q: 对话框
	1. 模式对话框
		- 启动时主窗口不可使用的对话框
	2. 非模式对话框
		- 启动时主窗口仍可处理事务的对话框
	3. 对话框与窗口的区别与相同点
		- 前者无法调节大小
		- 两者都可以移动与关闭

## Windows 7 的资源管理

3. Q: 库
	1. 库不会真正存储文件，只提供一种更快捷的管理方式
	2. 默认具备“视频”、“图片”、“文档”、“音乐”

4. Q: 文件或文件夹的选择
	1. 连续选择：Shift
	2. 非连续选择：Ctrl

5. Q: 剪贴板的工作
	1. 为了传递信息而在**内存**中开辟的一块临时存储空间
	2. 断电后信息会丢失

6. Q: 利用鼠标拖动管理跨目录文件

|     | 复制                   | 移动                    |
| --- | -------------------- | --------------------- |
| 同盘  | <kbd>Ctrl</kbd> + 拖动 | 拖动                    |
| 跨盘  | 拖动                   | <kbd>Shift</kbd> + 拖动 |

7. Q: 文件属性
	1. 常规
		- 只读
		- 隐藏
	2. 高级
		- 存档
		- 索引
		- 压缩
		- 加密

8. Q: 目录属性
	1. 除了上述属性外，还有一个属性
		- 共享

9. Q: 文件或目录名规则
	1. 最多 **255** 个字符
	2. 不能出现 `:`、`"`、`/`、`\`、`|`、`*`、`?`、`<`、`>`
	3. 文件名**不区分大小写**
	4. 同一目录下不允许有两个同名文件
